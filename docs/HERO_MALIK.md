# 马利克参战

2026-10-30，基准为 Dove 2.1.0.3／`1a863df0`。马利克完成 Godot 项目内验收；其余英雄仍为大厅预览，第 8 关未接入。本轮按用户要求在这里暂停，不重新导出 Web。原有 Web 包不包含本次英雄战斗；下次集中交付时重新导出并检查隔离 PCK。

在英雄大厅选中马利克后，他会进入源版允许英雄的战斗。点击左下头像或本人，再点有效道路位置即可移动；非法位置保留选择并提示，右键取消。死亡后自动取消指挥选择，头像禁用，复活后恢复。挑战的 `locked_hero` 限制保留，进入挑战不会清除大厅选择。

每局从 1 级／0 经验开始。普通攻击、带眩晕的重击、范围猛击、地震都按源模板和实际脚本实现；技能按等级解锁，地震同时向道路两端及其他主路传播，后续脉冲覆盖两条侧路。伤害经验使用实际减伤后的伤害，地震在选中技能时获得固定经验；每批经验独立四舍五入，一次结算最多升一级。升级回血并播放源动画。移动采用 Dove 网格 A* 和航点规则，期间不可被普通攻击选中，毒伤保留。

闲置回血保留源脱战等待和累计计时。普通死亡播放一次死亡动作并保持尸体，2 秒后换为墓碑；死亡起算 15 秒后播放复活动作，结束后满血恢复操作。解体、吞噬和寄生死亡分别处理隐藏与特效。初始／升级动画不可中断；地震碎石播放一次后隐藏，地面弹坑独立淡出并移除。

## 资源与实现

`data/hero_malik_combat` 为跨关卡复用的独立包，含 10 个模板、291 个帧引用（207 个独立帧）和 21 段动画，以及头像、状态和音效。模板来自隔离求值的实际源模板，数值以完整双精度写出，避免命中时间在 JSON 转换后偏移一帧。每个源文件及纹理保留哈希；隐式死亡特效也登记为依赖。

`battle_setup.gd` 加载选中的已实装英雄；`hero_combat.gd` 拒绝缺失字段或依赖，按源模式限制决定是否参战。`dove_heroes.gd` 管理本局英雄状态，`dove_grid_path.gd` 保留源堆排序、邻点顺序、迭代上限和航点转换。英雄模板、经验、生成器和渲染资源不跨局共享可变状态。
