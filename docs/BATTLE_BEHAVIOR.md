# 共用战斗行为

实现以 [当前 Dove 基准](GODOT_WEB_REMAKE_GUIDE.md) 为准，固定 30 Hz。行为通过显式源 ID 注册到共享模块；界面动画使用独立表现时钟，不改变模拟顺序或战斗随机数。

## 帧顺序与伤害

每帧依次更新：状态、上帧待插入实体、出生／自动开波、控制器、装饰、蜘蛛卵／生成器／光环、空间索引、塔、士兵、敌人、弹丸、清理与结算。同帧孵化先于胜利判断；未到期蜘蛛卵本身不阻止胜利。生命归零优先判负。

`dove_damage_factors.gd` 对齐 `all/script_utils.lua`：单位造成和受到的伤害系数均为 `(初始倍率 + 增益增量之和) × 减益倍率之积`，移除时执行逆操作。塔伤害增益加算，向所有现有驻军传播增量，新驻军继承塔总倍率。状态保存在本局实体中，不修改导出模板。

近战、范围近战、塔及敌方远程均使用对应攻击者倍率。弹丸在发射时保留发射者和倍率，发射者死亡／出售不改变在途弹丸；持续伤害与射线保留传入倍率。受到伤害倍率在护甲计算中统一应用。普通、物理、魔法、毒素与爆炸的护甲规则继续读取源伤害标志。

## 移动、弹道与状态

| 模块 | 行为 |
| --- | --- |
| `level01_sim.gd` | 普通移动、阻挡、近战、塔事务、出兵门、直线集结、帧顺序与结算 |
| `dove_projectile.gd` | 箭／炮弹重力和初速度解析采样、自转、隐藏半径、命中与特效 |
| `dove_arrow_missile.gd` | 精灵箭的追踪与命中 |
| `dove_modifiers.gd` | 状态过滤、持续伤害、减速、缠绕、沉默及生命周期 |
| `dove_targeting.gd` | 阵营、飞行、攻击／伤害可见性过滤及原目标优先级 |
| `dove_enemy_ranged.gd` | 射程上下限、停止前进、近远程切换与发射时间 |
| `dove_ranger.gd`、`dove_elf.gd` | 游侠技能、营地招募和精灵近远程动作 |
| `dove_paladin.gd`、`dove_arcane.gd` | 圣骑士技能、射线分段伤害、死亡射线和限次传送 |
| `dove_enemy_projectiles.gd`、`dove_spawner.gd`、`dove_juggernaut.gd` | Boss 导弹重选目标、投弹、召唤增长及死亡动作 |
| `dove_upgrades.gd` | 本局模板补丁、法师塔联动、反伤队列、火雨控制／焦土和高级援军 |

魔法弹执行源 `scripts.bolt.update` 的到达／yield 顺序：每步 `speed += 30 × speed × ceil(acceleration_factor / 30)` 后限制到源上下限。沿目标命中偏移追踪，任一轴突变超过 `max_track_distance` 后永久停止追踪，仍飞向保存落点播放特效。目标增加远程禁选标志不使已发出的魔法弹失效；目标死亡则不命中。初始即到达的弹丸尚未取得目标引用，不额外造成伤害。

弹丸附加状态使用 `mods` 列表，缺省时使用单个 `mod`；逐项按状态模板可见性过滤，保留发射者、倍率与等级。已有精灵流血、残废及游侠毒箭继续按各自源技能逻辑处理。

默认科技从独立本局配置解析，重开重新克隆模板，菜单与战斗共享生效数值。科技上限与塔升级上限分别处理。破甲伤害标志单独处理，不造成生命伤害；反伤使用原始入伤并延迟结算，弹丸不作为有生命的发射者反射。科技流血最多五层，移除／死亡时清理；法师塔联动按数量从基础值计算，不累计乘算。科技火雨按源分批生成，全局火雨执行路径预测，焦土按源周期和可见性过滤；详见 [默认科技](DEFAULT_UPGRADES.md)。

集结先解析合法地形、椭圆范围及阵型，解除阻挡与待结算近战，直接朝各自阵型点移动，途中不索敌。兵营补员先播开门，再插入士兵；皇家卫兵永久阵亡，不进入兵营补员。精灵射箭使用完整的上下方向动画，在源第 7/30 秒由弓口发射，不从身体中心生成。

## 验证入口

`tools/current_reference` 在隔离 LÖVE 中执行当前源的实际倍率函数和魔法弹协程，生成 `tests/fixtures/dove_current_source.json`；`tests/verify_current_dove.gd` 比较完整逐帧列表，记录首次差异，并检查倍率叠加／移除、驻军继承、状态来源、过滤与模板隔离。

首关、第三关、第五关短战斗样本覆盖实际攻击、弹丸、状态、孵化和 RNG；第六关专项覆盖高级塔与 Boss 边界。完整通关回放按需运行，具体命令见 [运行说明](RUNNING.md)。
