# 一代大地图与选关

主菜单“开始”进入 Dove 一代大地图；点击首关旗帜打开原版选关书页，再进入首关战役。暂停、胜利和失败均可返回地图，结算仍可重新开始。地图设置可以返回主菜单。

## 内容与来源

- 固定来源：Dove 2.1.0.2，提交 `e29ece82939fd73fb69bfc4b469d484a72e4dfd2`。
- 包含 1～26 与额外关卡 1000，共 27 个节点的源位置、名称、历史、缩略图、挑战规则和解锁分组。初始只显示首关旗帜；首关通关后出现第二关与道路。
- 一代地图 124 个动画实例经过模板展开，包括随机等待、循环、翻转、分层、云层移动、树人序列及大船进出港和交叉淡入淡出。
- 图集保留 `original_size / logical_size / trim / ref_scale`。英雄入口接入后，5246 个帧引用去重为 4235 个唯一帧，生成 13 张 2048² 派生图集；像素与原图逐帧一致。
- 数据导出在独立 LÖVE 环境内，仅允许读取地图纯数据模块；行为函数只记名，Godot 映射相应状态机。没有启动原版主程序、更新器、插件或访问原版存档。
- `data/map_kr1/manifest.json` 列出运行依赖与源纹理哈希，`definition.json` 记录源代码哈希与冻结提交；地图不依赖本机原游戏目录。

本轮只允许第一关普通战役开战。第二关解锁后可以查看书页，按钮注明“尚未实现”。英雄入口已开放全部 79 名英雄的资料、原版解锁与双选存档，详见 [英雄选择交付](HERO_SELECTION_DELIVERY.md)；科技、图鉴与成就仍未开放。不显示其他世代或自制地图切换。英雄挑战、铁人模式三星后可以查看源规则，均不能开战。战斗难度固定普通，无英雄参战、零科技、未选择第三法术。

## 模块与适配

- `campaign_progress.gd` 管理单代解锁、最好成绩、保存与待展示变化；解锁和战斗实现状态独立校验，应用路由再次检查开战请求。
- `map_loader.gd` 在菜单之后分帧加载地图独立依赖，缺失资源返回可重试错误。
- `map_screen.gd` 管理镜头、命中、路由信号及星星/道路/旗帜的通关反馈；`map_animations.gd` 管理装饰时钟；`map_interface.gd` 组合 HUD、选关书页和设置。
- 共用 `dove_ui_layout.gd` 通过参考高度参数支持战斗 768 与地图 1080 单位；图像本地变换同时处理缩放和镜像，文字与命中沿同一父变换。中文正文用 TextParagraph 测量、按源大字区域分段绕排，禁止分别猜测坐标。
- 地图离场释放场景、图集引用、声音池与监听；保留轻量镜头快照。返回地图恢复镜头，并展示尚未消费的通关变化。

| 地图操作 | 输入 |
| --- | --- |
| 选关与按钮 | 左键 |
| 上下平移 | 滚轮；鼠标靠近上下边缘 |
| 横向平移 | Shift＋滚轮；鼠标靠近左右边缘 |
| 触屏平移、缩放 | 单指拖动、双指捏合，范围 1～3 倍 |
| 关闭选关页 | Esc 或右键 |
| 打开地图设置 | 齿轮按钮；无弹窗时按 Esc |

弹窗阻挡地图平移、缩放及底层按钮；移动或缩放后清除旧命中区域，防止同帧点击旧位置。

## 进度

已扩展为 Dove 风格的三个固定存档槽，点击主菜单“开始”展开，新建/继续/删除分别处理。各槽 JSON 包含 schema_version、generation、content_version 和各关最好成绩，存放于 `user://saves/kr1/slot_1..3/campaign.json`。旧单槽文件自动迁入槽位 1 并归档，删除不会导致旧档重现。存档与全局音量分离，不导入 Dove Lua 存档，不保存战斗中途状态。调试局成绩正常保存。

战斗只提交一次完整结算；胜利立即保存，失败、退出和重开不增加成绩。18～20 生命三星、6～17 二星、1～5 一星；低成绩不覆盖高成绩，重复结算不重复加星。地图计数只统计一代，源关卡总上限为 135 星，包含暂未实现的挑战及额外节点。

先写临时文件，再保留有效旧进度为 `.bak` 并替换正式文件。损坏时恢复备份；新版未知格式保留原文件；无法保存时本次仍可继续并显示提示。测试使用独立路径，不修改玩家进度。
