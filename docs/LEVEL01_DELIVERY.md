## 重新生成与交付

在参考仓库保持冻结提交、安装了本机 LÖVE 和 Python/Pillow 时执行：

```powershell
python tools/prepare_level01.py
python tools/verify_level01_assets.py
```

重新生成后用 Godot 导入一次，再执行 RUNNING.md 中的逻辑与原生检查。需要交付时运行 `python tools/web_bootstrap.py export`，随后 `python tools/package_level01.py` 生成独立压缩包及启动脚本。运行压缩包只需要 HTTP 服务和支持 WebGL 2 的浏览器，不需要原游戏或 Godot 编辑器。
