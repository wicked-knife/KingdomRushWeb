# 第四关与四类三级塔交付

基准为 Dove `2.1.0.2`，提交 `e29ece82939fd73fb69bfc4b469d484a72e4dfd2`。第四关「双子河畔」普通战役与兵营、箭塔、炮塔、法师塔二升三已接通。范围保持普通难度、无英雄参战、零科技；第五关和挑战模式仍为预览。

## 关卡与资源

第四关使用源版背景、地形、两条路径、15 个塔位、备战及战斗音乐，初始 520 金币、20 生命，13 波共 339 名敌人：哥布林 130、兽人 58、萨满 24、盗贼 77、小狼 18、食人魔 2、强盗 30。强盗在源中文通知中的名称为「土匪」。盗贼保留 50% 近战闪避，强盗保留 50% 物理护甲，并接入对应动画、声音和新敌人通知。

入口按照源版标记排序后的数组序号关联波次。第四关两个源标记的 `editor.path_id` 均为 1，运行时入口序号分别为 1、2，并保留 `source_path_id` 供追溯；开波旗、分路敌人预告和路线高亮均使用运行序号。

第三关胜利后可进入第四关，已有通关第三关的存档无需迁移。第四关保存本关最好星级，并解锁第五关预览；新敌人的已读状态按存档槽保存，旧存档缺少该字段时兼容加载。前三关保持源版塔级限制。

`data/level04/` 随第四关加载：78 个模板、2341 个帧 ID（1173 个规范帧）、157 条动画、7 张派生图集及 61 个音频资源。来源校验覆盖 43 个输入。前三关的模板、规则、地形、路径、布局、波次和动画内容保持不变，仅补充升级菜单索引及可追溯入口字段。

冻结源波次引用 `TOWER_LEVEL3`，但 GUI 没有对应定义。本实现沿用二级通知适配方式，复用源纸张、标题和按钮补充三级塔说明；此页面是适配补充。

## 升级行为

| 防御塔 | 二升三费用 | 三级属性 | 累计投入／开波后退款 |
| --- | ---: | --- | ---: |
| 兵营 | 150 | 3 名骑士；150 生命、30% 护甲、8–12 近战伤害；集结范围 155 | 330／198 |
| 箭塔 | 160 | 11–20 物理伤害；射程 180；间隔 0.5 秒 | 340／204 |
| 炮塔 | 320 | 36–72 爆炸伤害；射程 180；间隔 3 秒；爆炸半径 67.2 | 665／399 |
| 法师塔 | 240 | 47–82 魔法伤害；射程 180；间隔 1.5 秒 | 500／300 |

继续使用 `upgrade(id, upgrade_to)`。目标须在本关模板中存在，且符合相邻等级、同类和关卡限制；金币不足、建造中、暂停、通知未关闭、已经结算和重复命令均不会扣款或改变战斗状态。升级保留塔位、位置、地形和集结点，继续累计投入；首波前全额退款，开波后按源比例退款。

远程塔取消未发出的攻击，已经发出的弹体继续使用原模板结算。兵营将存活步兵替换为满血骑士，迁移位置、朝向及攻击时间戳，取消旧攻击并更新阻挡引用；死亡缺员由三级兵营正常补齐。骑士按源版严格冷却边界执行 42 tick 周期；法师名义间隔为 1.5 秒，严格边界在 30 Hz 模拟中为 46 tick。

界面按目标模板索引菜单，显示对应三级名称、说明、价格和金币不足状态；前几关显示各自等级限制。独立三级测试场为 `tests/tier3_upgrade_arena.tscn`，使用第四关资源、2500 初始金币和独立设置，不连接战役存档。原二级测试场保留。
