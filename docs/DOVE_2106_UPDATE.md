# Dove 2.1.0.6 同步

当前源提交为 `4072b18bf4e418eec8b813a960c83003744cb710`。源码仓库已快进至该提交，安装素材按同一提交重新同步；安装目录只读。当前开放范围为前八关战役、英雄挑战、钢铁挑战，共 24 个组合，默认科技方案 1，马利克参战。

本次更新包括：

- 接入拆分到 `kr1/heroes/<name>/` 的英雄声明、模板、动画和音频。动画合并按注册顺序执行并拒绝冲突；转换缓存记录所有模块输入哈希，模块变化不会错误复用旧结果。
- 英雄大厅从 79 名扩展到 91 名，导出 445 条技能说明；新增英雄保留源解锁关卡，只开放预览。矮人、吸血女、波尔维克三张已确认立绘继续使用。
- 更新火雨：零、一级无焦土；二、三级焦土伤害为 10–20，持续 5 秒；四级起为 20–30、10 秒。模式上限作用于有效等级。陆地、水面均沿源伤害协程检查命中时刻和到期清理。
- 同步流血特效的缺失血色处理：持续伤害、结束和实体清理照常，无血色单位不插入血迹特效。奥术射线已有复数／单数 modifier 支持，保留专项回归。
- 马利克参考采样直接执行新版模块中的真实函数，战斗适配仍使用原回调标识。重新采样后的马利克行为值与旧样本一致。

前八关波次、路线、布局、初始资源、禁塔及限制保持源配置。新图集重新排布了信息头像坐标，增加两条出血动画别名；蛮族技能表的遍历顺序来自源表，不影响各技能升级结果。

`tests/fixtures/dove_2106_delta.json` 精确列举已审阅差异，并记录更新前 36 份逻辑文件指纹。`tools/verify_dove_update.py` 反向投影这些差异后必须复现旧指纹，同时核验当前源码输入哈希。历史战斗、科技增量、七／八关增量快照保持原文件；原有属性、动画帧、升级边的篡改拒绝检查继续运行，并补充错误灼烧值与过期源提交的拒绝检查。

验证证据包括 `reports/dove_2106_transition.json`、`reports/upgrades_logic.json`、`reports/heroes_logic.json`、`reports/heroes_visual_1280x720.json`、`reports/hero_combat_logic.json`、`reports/content_unification.json` 及七／八关专项。画面、输入、音频在 Godot 原生窗口检查。没有以完整挑战通关作为验收前提。最终 Web 包集中导出一次并检查隔离 PCK，浏览器功能与兼容性由用户手动验收。
