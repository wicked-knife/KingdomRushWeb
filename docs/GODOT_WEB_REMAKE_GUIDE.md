# Kingdom Rush Web 复刻指南

所有玩法、数据、界面与存档语义以 **Dove 最新源码** 为准。当前同步版本为 **2.1.0.3**，提交 `1a863df00b08f6bf1018ae0b0e7e4e106b939082`；机器可读基准只登记在 `data/campaign_content.json` 的 `source`，各导出工具统一读取。源码目录为 `D:/projects/KingdomRushDove`，安装素材目录为 `D:/王国保卫战Dove版/KingdomRushDove`。更新时保持源码干净，先拉取，再更新目录基准、同步素材、转换与验证。

## 当前可玩范围

- 前六关战役、英雄挑战、钢铁挑战，共 **18 个组合**；普通难度 2、零科技、无英雄参战，第七关为预览。
- 四类基础塔及二、三级升级；游侠、圣骑士、奥术塔与全部已接入技能；第五关精灵营地，第六关独立皇家卫兵、飞行敌人、暗影弓箭手和毁灭者。
- 首关教学、通知、暂停、倍速、两项技能、单位信息、集结、提前开波、胜负与返回地图流程。
- 一代地图及挑战入口、三份独立存档、两阶段结算。英雄房间可浏览 79 名英雄、选择最多两名，选择保存在槽位中，暂不参战。
- Web 为发布目标；日常使用 Godot，浏览器验收由用户手动完成。
