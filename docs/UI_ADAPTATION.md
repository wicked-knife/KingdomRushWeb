# Dove 界面适配约定

前六关教程、HUD、技能栏、选塔菜单、暂停及结算共用这些约定。后续新增界面复用 `scripts/battle/dove_ui_layout.gd`，组合定义集中在 `battle_ui.gd`，不再在战场绘制代码中分别估算图片、文字和点击位置。

## 坐标与资源

战斗 UI 使用 768 高度参考坐标，大地图使用 1080；创建布局组件时显式传入参考高度，默认仍为 768。图集裁切区为纹理像素，显示尺寸为 `original_size × ref_scale × reference_height/1080`；裁切偏移 `trim` 以同一比例恢复。图片可见区域不能代替原始画布作为布局尺寸，否则透明边距会导致标题、图标、价格和按钮错位。镜像和缩放放在局部 Transform2D 中，不能依赖负绘制矩形维持源锚点。

每个界面先在其自然尺寸内完成排版，再由父级统一等比缩放并居中。文字、背景及命中区域通过同一个 `Transform2D`；输入只做一次视口坐标转换。宽屏扩展战场时，HUD 分别依附左右边缘，弹窗按可用宽高和安全边距整体收缩。固定纸张、木板、装饰边框保持比例；仅源定义允许的进度条、音量填充条可以沿单轴缩放。需要九宫格的新增底板必须声明源拉伸区域，不得拉伸整张带装饰的背景。

`tools/level01_export/main.lua` 在隔离的 LÖVE 中提取 `game_gui_data.lua` 的中文 CJK 分支、教程全部文本框、气泡和选塔菜单定义。模板行为不执行。文字使用当前源码中的简体中文翻译，保留逐项 `pos / size / anchor / font_name / font_size / color / text_align / vertical_align / r`。源文件 SHA-256 和提交记录在首关 manifest 中。

## 文字与组件

所有文字必须声明文本框。`TextParagraph` 按中文规则排版、测量并在框内调整字号，禁止用手工基线位置猜测居中。文字不可越过背景中的对话框或按钮内容区。对齐、换行和字号审计同时保留，不能靠裁切隐藏溢出。正文、标题、价格、按钮分别沿用源样式；教程正文不加 HUD 的粗描边。

原版标题带、纸张和按钮有叠放关系：标题先绘制，纸张覆盖其下沿，再绘制纸上内容。暂停使用 `options_bg_notxt`，失败使用 `defeat_bg_notxt`，战役胜利使用 `victoryBadges_notxt_0002`；不得跨组件借用一张相似背景。暂停音量条连接现有设置服务和 Music/SFX 总线，保留同一份用户设置。

共享字体服务 `dove_fonts.gd` 按当前版本 font_subst 的 global/default/zh-Hans 顺序解析别名：JIMOJW 用于标题和按钮，微软雅黑用于正文及其粗体，Comic Book Italic/TOONISH 用于数字。源角色的 size 和垂直调整只应用一次；字体、文字框、换行与测量缓存使用同一配置，缓存键包含字体身份及角色。教程文字继承源 create_slide 的 body_slides，气泡继承 TutorialBalloon 的 body，不猜测缺省字体。

FontFile 禁用系统字体回退，显式连接包内微软雅黑和 Noto 字形。所有 Canvas 字体缓存采用 3 倍 oversampling。主菜单 Label 同样使用服务提供的字体角色并按文字框缩小字号；书页首字绕排用正文同一配置重新测量。HUD 生命、金币在图标之间的独立安全区中双向居中，数值过长时缩小字号。禁止重新引入单一默认字体或独立估算文字基线。

短标题与段落使用不同测量方式。页签、首字和“进入战斗”使用 `display_label`：从 TextServer 的实际字形、偏移与回退字体计算可见边界，在图内内容区居中；不因字体内部留白而将短标题过度缩小。描边纳入内容区测量，并按字体缓存的 oversampling 转换栅格描边宽度，避免小字描边断裂。普通说明继续使用段落行高与自动换行。书页保留首字旁的强制换行，剩余中文按 Dove 的 `add_level_description` 合并，不保留翻译文件中的额外空段。

从 KView 导入旋转时取反：原版 `_draw` 调用 `G.rotate(-r)`。存档统计保留 `slot_view.lua` 的位置、12 号 `numbers_italic`、黑色、顶端对齐和无描边；仅统计组旋转，不能套用菜单标题样式。选关模式页签使用源定义的 68 宽内容区、普通/选中横向锚点 40/53、正文角色及对应的棕色/浅蓝色；锁定切图已有禁用外观，不重复压暗。难度图标下不增加原版没有的文字。

地图右上角星星计数依据实际使用的 `map_counters_view.lua`：30 号 `numbers_bold`（TOONISH），110×36 内容区，`middle-caps` 对齐，金色文字及 (2,2) 深色阴影。不能与存档统计的斜体角色混用；此处不使用旧版未接入的 `StarsBanner` 数字图片实现。

## 选塔与建造

选塔按钮来自 `tower_menus_data.lua`：`main_icons_0001..0004`，叠加 `main_icons_0000` 边框、`price_tag` 和对应悬停光环。预览塔只在悬停时显示在塔位，保留源偏移、透明度和射程；不能将预览塔充当菜单按钮。

菜单使用源按钮位置，0.12 秒 out-quad，从 0.6 倍缩放、透明过渡到正常状态；入场期间不接受购买。关闭时缩小淡出。锁定升级、出售与集结使用各自图标。选择范围、图标、价格和点击区域随菜单共同变换，并避让窗口边缘。

建造时间读取模板 `build_duration`；建造图、进度条背景和进度条按源多层 sprite 显示。进度条从本次购买 tick 开始，读取源 tween 的 `sprite_id / keys / scale`，保持左端固定。完成时移除建造实体显示，切换成塔，并播放原买塔尘土单次动画和完成语音。建造期间不接受选塔操作。

命令改变交互模式后立即清除旧命中区域，防止同一渲染帧内连续点击触发已关闭的菜单。

## 共用交互与表现

选择光圈读取源 selected_small/med/big、友军标记与 unit.marker_offset，先于单位绘制。集结使用 decal_rally_feedback 和 pointer_set_rally；成功后在解析出的实际落点播放 1.5 秒淡出反馈。火雨为 32 帧、援军为 10 帧组合落点动画，使用源技能图标和锚点。进入模式立即隐藏系统鼠标，取消、施放、暂停、通知、结算、重开、离开窗口及失焦恢复；无效落点只播放红叉，不消费冷却和 RNG。

首波单击，后续双击同一入口提前开波；跨入口、跨波次不合并，空格保留。预告按标题、敌人列表测量自适应，箭头与弹窗共同避让和淡入淡出。锁定、金币不足、满级按钮静默消费点击，保留选择和说明，交易层仍校验。

高级塔和营地技能等级灯读取源 tower_menu_power_offset，购买成功点亮并播放 23 帧 effect_powerbuy，菜单保持打开，立即刷新价格和说明；满级保留图标和等级灯，隐藏价格与购买光晕。切塔、出售、重开和退出清除反馈状态。

胜利页使用各模式徽章、弧形标题、星星和链条按钮，不添加生命／击杀／波数统计。弹出 0.6 秒，0.65 秒后开始星星与音效，再依次展开按钮，展开后才可点击。粒子 RNG 独立于战斗，两阶段结算及返回地图语义不变。

## 新界面验证

先收集当前源布局、文案、图片与动画，记录输入哈希，再以自然坐标构建并统一缩放。字体测量、绘制和命中变换保持一致，覆盖长中文、最大数字、禁用、冷却和遮挡。原生检查主分辨率及必要的受影响边缘布局，查看截图和关键动画帧；无需为局部 UI 改动重跑完整战役。交付集中导出，隔离 PCK 与浏览器手动验收分开记录。详见 [验证范围](TEST_REDUNDANCY_REVIEW.md)。
